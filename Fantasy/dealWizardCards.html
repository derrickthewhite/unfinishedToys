The GNDT feild should contain a copy-pasted version of the GNDT table. tabs seperate feilds, and \n seperates lines.

The Card list should be copied from the Deck rule. No cards should be removed.

The seed is run as a string, though in practice it will almost always be the string of a number. I am using the davidbau seedRandom js Library

This page does not use php, only javascript.

The initial values provided in the GNDT and Card List text areas are the valid values as of July 2nd, 2018. They are only for use in testing and demonstration. You will need to populate them yourself to use this tool.
